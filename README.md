# AnyFly · 未见之地

Public desktop installers and signed automatic updates for AnyFly.
Downloads do not require a GitHub account or authentication token.

- [Download the latest release](https://github.com/velnora-client/nautilus-release/releases/latest)
- [Download catalog](https://anyfly.net/desktop/)
- [Update feed](https://github.com/velnora-client/nautilus-release/releases/latest/download/latest.json)
- [Recovery address](https://www.anyfly.org/)

Choose the installer for macOS (Apple Silicon or Intel), Windows x64, or Linux
(x86_64 or ARM64). Each release includes SHA-256 checksums and signed updater
payloads. This repository contains distribution artifacts; application source
and build credentials are not stored here.

Disconnect and quit before installing, upgrading, or uninstalling.

On macOS, the application is ad-hoc signed and distributed without Apple
notarization. If the first installation or launch is blocked, use System
Settings → Privacy & Security → Open Anyway, then approve the installer's
administrator prompt. [Apple's instructions](https://support.apple.com/en-us/102445).

On Windows, SmartScreen may show an unrecognized-app prompt. Use More info →
Run anyway when available; organization-managed devices may require
administrator approval.
